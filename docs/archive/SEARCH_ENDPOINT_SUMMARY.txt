ENDPOINT SPECIFICATION
================================================================================

Endpoint:       GET /api/maps/search
Base URL:       http://localhost:8000/api/maps
Route:          /search

Query Parameters:
  q (required)      string    Search query (min 1 character)
  live (optional)   boolean   Enable live geocoding (default: false)

Response (200 OK):
{
  "query": "string",           // Search query submitted
  "results": [                 // Matching neighborhoods (max 5)
    {
      "id": 1,                 // Unique neighborhood ID
      "name": "Sector 17",     // Neighborhood name
      "city": "Chandigarh",    // City name
      "state": "UT",           // State abbreviation
      "latitude": 30.7439,     // Geographic latitude
      "longitude": 76.7955     // Geographic longitude
    }
  ],
  "count": 1                    // Number of results
}

Error Responses:
  422 Unprocessable Entity  - Missing or invalid query parameter
  500 Internal Server Error - Unexpected error (returns empty results)
