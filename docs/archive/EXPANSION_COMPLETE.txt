KNOWN LIMITATIONS & WORKAROUNDS
================================================================================

Limitation 1: Search Results Limited to 5
  - Reason: API contract specification
  - Impact: Users refine search for specific areas
  - Workaround: Search by exact sector number (e.g., "17")
  - Status: ACCEPTABLE (by design)

Limitation 2: Static Scores (No Real-Time Updates)
  - Reason: Would require live API integration
  - Impact: Scores may not reflect immediate changes
  - Workaround: Schedule monthly data refreshes
  - Status: ACCEPTABLE (typical for neighborhood apps)

Limitation 3: Gemini API Quota Exhausted
  - Reason: Free tier limited by Google
  - Impact: Summary generation falls back to message
  - Workaround: Upgrade to paid tier or use fallback gracefully
  - Status: HANDLED (graceful degradation implemented)

Limitation 4: No Public Transit Real-Time Data
  - Reason: Chandigarh CTU has no public API
  - Impact: Connectivity scores are approximated
  - Workaround: Use OSM public transit layer (implemented as option)
  - Status: ACCEPTABLE (future enhancement)

None of these limitations affect core functionality or production readiness.
