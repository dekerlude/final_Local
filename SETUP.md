## **Quick Start**

### **1. Install Dependencies**

```bash
npm install
```

Or if you prefer yarn/pnpm:

```bash
yarn install
# or
pnpm install
```

### **2. Set Up Environment Variables**

Copy the example file and add your API tokens:

```bash
cp .env.example .env.local
```

Edit `.env.local` and add:
- `NEXT_PUBLIC_MAPBOX_TOKEN` (for map previews)
- `OPENAI_API_KEY` (optional, for real AI summaries)

### **3. Start Development Server**

```bash
npm run dev
```

The application will be available at: **http://localhost:3000**

## **Development Tips**

### **Hot Reload**
The dev server automatically reloads when you save files.

### **TypeScript**
- TypeScript is configured with `strict: true`
- Path alias `@/*` maps to `src/*`
- Types are checked automatically during dev

### **Tailwind CSS**
- JIT compilation (only included CSS that's used)
- Dark mode support with `dark:` prefix
- Custom colors defined in `tailwind.config.js`

### **Next.js Features**
- **App Router**: File-based routing in `src/app/`
- **File conventions**:
  - `page.tsx` = page component
  - `layout.tsx` = layout wrapper
  - `error.tsx` = error boundary (if added)
  - `loading.tsx` = loading UI (if added)
